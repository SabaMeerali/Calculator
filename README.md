# Calculator
A simple calculator application built using Java Swing for the graphical user interface (GUI). This project performs basic arithmetic operations with an easy-to-use design.

Features
User-friendly Java Swing GUI with a clean, minimal design.
Basic arithmetic operations: Addition (+), Subtraction (−), Multiplication (×), and Division (÷).
Clear functions:
CE – Clear the current entry.
C – Clear all input.
← – Backspace to delete the last digit.
± button – Toggle between positive and negative numbers.
Decimal point (.) support for floating-point calculations.
Equals (=) button to display results instantly.

Technologies Used
Java (JDK 8 or later) – Core programming language
Swing – For building the graphical user interface
NetBeans IDE – For designing and coding the application
